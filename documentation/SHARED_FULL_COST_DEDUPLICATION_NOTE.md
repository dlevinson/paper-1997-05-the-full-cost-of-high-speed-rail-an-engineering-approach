# Shared Full Cost Deduplication Note

This package is part of the broader Berkeley Full Cost Project lineage. The HSR-specific workbooks and notes are retained here because they directly match the 1997 high-speed rail paper.

Some general Full Cost Project assets also appear in the related air, highway, social-cost, and California corridor packages. These include the air-noise workbook, Table 7 intermodal comparison workbook/text extract, highway noise model, and UCB-ITS-RR-96-3 report front matter. Those shared files should be uploaded once in a shared Full Cost Project source package or referenced by one canonical paper package, with the other paper packages using README pointers rather than duplicate GitHub copies.

For the chronological cleanup pass, this note records the deduplication boundary without treating the duplicated source lineage as a separate permission problem. The paper-first validation found no human-subject microdata or private data in this package.
